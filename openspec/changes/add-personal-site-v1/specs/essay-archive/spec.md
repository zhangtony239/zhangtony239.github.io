# Spec Delta

## Purpose

提供一条只读的极简时间流，让读者用最少的视觉噪音浏览全部随笔，并按年份快速定位到某一时期的写作。

## ADDED Requirements

### Requirement: 归档每行只有日期与标题

归档中的每篇随笔 MUST 只呈现为一行，该行 MUST 仅包含发布日期与标题两项信息。归档 MUST NOT 呈现摘要、封面图、标签、阅读时长或作者信息。

#### Scenario: 每行只有日期与标题

- **WHEN** 用户打开 `/essays`
- **THEN** 每篇随笔表现为单独一行，行内只有日期与标题

#### Scenario: 不出现摘要与封面

- **WHEN** 归档渲染完成
- **THEN** 页面中不存在摘要文字、封面缩略图、标签或阅读时长

### Requirement: 按年份分组并倒序

归档 MUST 以年份作为分组标题，年份 MUST 按倒序排列，同一年内的随笔 MUST 按发布日期从新到旧排列。

#### Scenario: 年份分组

- **WHEN** 随笔分布在多个年份
- **THEN** 每个年份作为分组标题出现一次，其下的条目按发布日期从新到旧排列

#### Scenario: 同年内排序稳定

- **WHEN** 同一年内存在发布日期相同的随笔
- **THEN** 这两篇的相对顺序在每次构建中保持一致

### Requirement: 单页无分页

归档 MUST 在单个页面上列出全部已发布随笔，MUST NOT 提供分页控件或将条目拆分到多个页面。

#### Scenario: 全部条目在同一页

- **WHEN** 归档打开
- **THEN** 所有已发布随笔都出现在文档中，且不存在下一页或页码控件

### Requirement: 归档排除固定页面

归档 MUST 排除 `p/acc` 宣言页以及其他被标记为固定页面的文档；这些文档 MUST 仍可通过导航或固定链接直接访问。

#### Scenario: p/acc 不出现在归档

- **WHEN** 归档渲染完成
- **THEN** `p/acc` 的标题不在列表中出现，而导航中的 `p/acc` 条目仍可打开该页面

### Requirement: 草稿不发布

被标记为草稿的随笔 MUST NOT 出现在归档中，且构建 MUST NOT 为其生成可通过 URL 访问的页面。

#### Scenario: 草稿被彻底排除

- **WHEN** 一篇随笔被标记为草稿且站点被构建
- **THEN** 该随笔既不出现在归档中，其固定链接也返回未找到

### Requirement: 条目行的悬停与整行可点

归档的每一行 MUST 作为单个链接整体可点击。悬停时该行 MUST 出现淡蓝底色，且标题 MUST 切换为 `#2F6FE0`。

#### Scenario: 悬停一行

- **WHEN** 指针悬停在某一行上
- **THEN** 该行出现淡蓝底色，标题变为 `#2F6FE0`，日期颜色加深

#### Scenario: 点击整行任意位置

- **WHEN** 用户点击该行内除链接文字外的空白区域
- **THEN** 仍然打开对应的随笔
