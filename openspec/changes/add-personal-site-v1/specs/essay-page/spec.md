# Spec Delta

## Purpose

定义全站唯一的阅读体验：一篇随笔从标题到正文的统一排版，以及 `p/acc` 价值观宣言页对该模板的复用与它的可见性边界。

## ADDED Requirements

### Requirement: 全站只有一个正文模板

所有随笔与 `p/acc` MUST 由同一个正文模板渲染，MUST NOT 为 `p/acc` 单独设计版式。阅读栏宽度 MUST 为单列约 62 个字符。

#### Scenario: 随笔与 p/acc 版式一致

- **WHEN** 用户分别打开任意随笔与 `p/acc`
- **THEN** 两者使用相同的单列阅读宽度、字号层级与段落间距

### Requirement: 正文排版基线

正文 MUST 使用次要文字色 `#55637A`，行高 MUST 不小于 1.8，段落之间 MUST 有可见间距；正文 MUST NOT 出现彩色文字或强调色文字。

#### Scenario: 长文可读性

- **WHEN** 一篇长随笔被显示
- **THEN** 正文以 `#55637A`、行高不小于 1.8 呈现，行宽约 62 字符

#### Scenario: 正文内不出现强调色

- **WHEN** 正文包含普通段落文字
- **THEN** 不存在被渲染为 `#2F6FE0` 或 `#ADD0F5` 的段落文字

### Requirement: 文章元信息最小化

文章页在正文之上 MUST 只呈现标题与发布日期。MUST NOT 呈现标签、作者卡片、阅读时长、上一篇/下一篇链接或目录。

#### Scenario: 顶部只有标题与日期

- **WHEN** 任意随笔或 `p/acc` 打开
- **THEN** 正文之前只有标题与日期两项，没有标签、作者信息或翻页链接

### Requirement: p/acc 固定链接

宣言 MUST 固定发布在 `/p/acc`，导航中的对应条目 MUST 文案为 `p/acc`，且站点 MUST NOT 为同一文档再暴露其他路径。

#### Scenario: 打开固定链接

- **WHEN** 用户访问 `/p/acc`
- **THEN** 宣言以共用的正文模板呈现

#### Scenario: 不存在别名路径

- **WHEN** 站内任意链接指向宣言
- **THEN** 该链接都指向 `/p/acc`，不存在第二个人类可用的路径

### Requirement: 宣言不进归档与聚合输出

宣言 MUST NOT 出现在 `/essays` 归档中，也 MUST NOT 进入任何聚合输出（含未来可能新增的订阅源）。

#### Scenario: 宣言只能从导航与固定链接进入

- **WHEN** 生成任一列表或聚合产物
- **THEN** 宣言都不在其中，唯一入口是导航条目与 `/p/acc` 本身

### Requirement: 文章文档标题

每个文章页 MUST 拥有与该文标题一致的文档标题，使浏览器标签页与分享预览可辨识。

#### Scenario: 标签页显示文章标题

- **WHEN** 用户打开某篇随笔
- **THEN** 浏览器标签页标题包含该随笔的标题

### Requirement: 页面内只有一个一级标题

文章页 MUST 只包含一个一级标题，即由模板渲染的文章标题。正文 MUST NOT 再出现第二个一级标题，章节标题 MUST 从二级标题起。

#### Scenario: 正文标题层级正确

- **WHEN** 正文包含章节结构
- **THEN** 页面中只有一个 `h1`，章节使用 `h2`，小节使用 `h3`

### Requirement: Markdown 结构元素可读呈现

正文 MUST 支持二级/三级标题、引用块、有序与无序列表、表格、行内代码与强调。这些元素 MUST 使用设计令牌色，MUST NOT 呈现浏览器默认的蓝色链接色或默认表格边框。

#### Scenario: 标题层级有可见差异

- **WHEN** 正文同时包含二级与三级标题
- **THEN** 二级标题的字号与上间距明显大于三级标题，且两者都不是正文字色以外的强调色

#### Scenario: 引用块突出而不缩进成默认样式

- **WHEN** 正文包含引用块
- **THEN** 引用块以左侧 1px 细线区分、字号略大于正文，而不是浏览器默认的斜体加缩进

#### Scenario: 行内代码与列表标记使用令牌色

- **WHEN** 正文包含行内代码或列表
- **THEN** 行内代码有可见底色与等宽字体，列表标记为弱化色，二者均不出现未定义的色值

### Requirement: 宽表格不破坏阅读栏

当正文表格宽度超过阅读栏时，表格 MUST 允许比正文更宽，或在其容器内横向滚动；任何情况下 MUST NOT 导致整页出现横向滚动条。

#### Scenario: 四列长单元格表格

- **WHEN** 正文包含四列且单元格文字较长的表格
- **THEN** 宽屏下表格可比正文栏更宽，窄屏下表格自身横向滚动，页面本身不出现横向滚动条
