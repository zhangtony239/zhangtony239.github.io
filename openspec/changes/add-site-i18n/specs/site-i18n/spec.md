# Spec Delta

## Purpose

让站点以英文、简体中文、日文三种语言完整呈现：定义语言集合与带语言前缀的路径、根路径的语言入口跳转、右上角语言胶囊切换，以及每页的语言声明与三语 alternate 链接。

## ADDED Requirements

### Requirement: 受支持语言集合与默认语言

站点 MUST 恰好支持三种语言：英文 `en`、简体中文 `zh-cn`、日文 `ja`，并且 MUST 把 `en` 作为默认语言与最终回落语言。

#### Scenario: 语言集合固定

- **WHEN** 用户查看任意页面提供的语言选项
- **THEN** 可选项恰为 English、简体中文、日本語三项，且不存在第四种语言入口

#### Scenario: 无法判定语言时回落英文

- **WHEN** 浏览器语言不属于受支持语言，或语言信息不可用
- **THEN** 用户被带到英文版页面，而不是中文版或空白页

### Requirement: 语言前缀路径方案

每个内容页面 MUST 只通过带语言前缀的路径提供：`/en/...`、`/zh-cn/...`、`/ja/...`；站点 MUST NOT 再提供不带语言前缀的内容页面（入口 `/` 除外）。

#### Scenario: 三语路径互为镜像

- **WHEN** 用户访问 `/zh-cn/essays` 或 `/ja/essays`
- **THEN** 两者都返回随笔归档页，路径差异仅在于语言前缀

#### Scenario: 未加语言前缀的旧路径不再提供

- **WHEN** 用户访问 `/essays`、`/what-is-p-acc` 等缺少语言前缀的旧地址
- **THEN** 该地址不存在内容页面，站点不返回任何语言版本的内容

### Requirement: 根路径按浏览器语言跳转

访问 `/` 时，站点 MUST 依序以下列来源决定目标语言并跳转到该语言的首页：已持久化的手动语言选择、浏览器首选语言、默认语言 `en`。

#### Scenario: 浏览器语言匹配简体中文

- **WHEN** 首次访问 `/` 且浏览器首选语言为 `zh-CN`、`zh` 或 `zh-Hans`
- **THEN** 用户被带到 `/zh-cn/`

#### Scenario: 浏览器语言匹配日文

- **WHEN** 首次访问 `/` 且浏览器首选语言为 `ja` 或 `ja-JP`
- **THEN** 用户被带到 `/ja/`

#### Scenario: 浏览器提供了多语言偏好

- **WHEN** 首次访问 `/` 且浏览器按优先级给出多个语言，其中包含一个受支持语言
- **THEN** 跳转目标是这些偏好中优先级最高的受支持语言，而非列表里的任意一种

#### Scenario: 手动选择优先于浏览器语言

- **WHEN** 用户此前手动选择了 `ja`，随后以首选语言为英文的浏览器访问 `/`
- **THEN** 用户被带到 `/ja/`，手动选择优先

#### Scenario: 脚本被禁用时仍能进入站点

- **WHEN** 客户端 JavaScript 被禁用访问 `/`
- **THEN** 页面以静态方式跳到 `/en/`，并在页面上显示 English、简体中文、日本語 三个可见的语言链接

### Requirement: 手动语言选择被持久化

用户通过语言胶囊切换语言时，站点 MUST 记录该选择，使其在后续访问 `/` 与后续页面切换中被优先采用。

#### Scenario: 选择被记住

- **WHEN** 用户通过语言胶囊从 `/en/essays` 切到 `/ja/essays`
- **THEN** 该选择被保存，之后访问 `/` 时直接进入 `/ja/`

#### Scenario: 存储不可用时切换仍然有效

- **WHEN** 浏览器禁用了本地存储或写入失败
- **THEN** 语言切换照常完成并进入目标语言页面，不出现报错提示或跳转失败

### Requirement: 右上角语言胶囊

站点 MUST 在视口右上角渲染一个固定的语言胶囊，包含 English、简体中文、日本語 三个条目，当前语言条目 MUST 被标示为当前项；该胶囊 MUST 独立于居中主导航胶囊，且不改变主导航的条目集合。

#### Scenario: 胶囊出现在右上角

- **WHEN** 任意页面被显示
- **THEN** 语言胶囊固定在视口右上角、与主导航胶囊位于同一水平区域但互不重叠，滚动时保持可见

#### Scenario: 当前语言被标示

- **WHEN** 用户位于 `/ja/` 下的任意页面
- **THEN** 日本語 条目呈现为当前项，English 与 简体中文 条目呈现为可切换状态

#### Scenario: 窄屏下收起为当前语言入口

- **WHEN** 视口宽度不超过 600px
- **THEN** 语言胶囊收起为只显示当前语言的单个入口，展开后才列出三个条目，且此时不与居中的主导航胶囊重叠

#### Scenario: 中等宽度显示短码条目

- **WHEN** 视口宽度在 601px 到 900px 之间
- **THEN** 三个条目以短码（`EN`、`中`、`日`）在同一行内常显、不换行，每个条目的无障碍名称仍是该语言全称

#### Scenario: 宽屏下三个条目使用全称

- **WHEN** 视口宽度大于 900px
- **THEN** 三个条目以 English、简体中文、日本語 常显于同一行，且不遮挡居中的主导航胶囊

#### Scenario: 键盘可操作

- **WHEN** 用户用 Tab 键在页面中移动焦点
- **THEN** 语言胶囊的每个条目依次获得焦点并显示可见焦点指示，可用 Enter 激活

#### Scenario: 屏幕阅读器可识别

- **WHEN** 屏幕阅读器读取语言胶囊
- **THEN** 胶囊带有语言切换的无障碍名称，且条目文本使用各语言的自称（English、简体中文、日本語）

### Requirement: 切换到同一页面的对应语言版本

用户点击语言胶囊时，站点 MUST 跳转到当前页面在目标语言下的同一页面，而非目标语言首页；仅当该页面在目标语言下不存在时，才 MUST 回落到目标语言首页。

#### Scenario: 文章页保持同一篇文章

- **WHEN** 用户在某篇文章页面点击另一语言条目，且该文章存在该语言译文
- **THEN** 用户进入同一文章的该语言译文页面，其路径与当前页面仅在语言前缀上不同

#### Scenario: 归档页保持在归档页

- **WHEN** 用户在 `/en/essays` 点击 简体中文
- **THEN** 用户进入 `/zh-cn/essays`

#### Scenario: 缺少对应译文时回落首页

- **WHEN** 当前页面在目标语言下没有对应版本
- **THEN** 用户进入该语言的首页，而不是收到错误页

### Requirement: 页面语言声明与三语 alternate 链接

每个页面 MUST 用 `lang` 属性声明其实际语言，并 MUST 输出指向三语版本与 `x-default` 的 alternate 链接，`x-default` MUST 指向英文版本。

#### Scenario: 语言属性与页面一致

- **WHEN** 用户打开 `/ja/essays`
- **THEN** 文档 `lang` 为 `ja`，且页面文字为日文

#### Scenario: alternate 链接覆盖三语

- **WHEN** 抓取 `/zh-cn/` 的 HTML
- **THEN** 其中包含指向 `/en/`、`/zh-cn/`、`/ja/` 的 `hreflang` alternate 链接，以及指向 `/en/` 的 `x-default`

#### Scenario: 只声明真实存在的译文

- **WHEN** 某篇文章只有中文与英文译文
- **THEN** 其 alternate 链接只包含 `en`、`zh-cn` 与 `x-default`，不声明不存在的日文版本

### Requirement: 站点外壳文案来自语言字典

导航条目、页面标题、空状态、页脚与 AIGC 披露等站点外壳文案 MUST 取自当前语言的文案字典，页面 MUST NOT 内联硬编码单一语言文案。

#### Scenario: 导航随语言变化

- **WHEN** 用户在 `/en/` 与 `/zh-cn/` 之间切换
- **THEN** 主导航的三个条目文字随语言变化，而链接数量与顺序不变

#### Scenario: 字典缺项不影响可用性

- **WHEN** 当前语言字典缺少某条外壳文案
- **THEN** 该处回落到默认语言的文案，页面不显示文案键名、空白或报错

#### Scenario: 除入口页外不依赖脚本

- **WHEN** 客户端 JavaScript 被禁用
- **THEN** 所有语言版本页面的导航、归档、正文与语言胶囊链接均可用，语言切换通过普通链接完成
