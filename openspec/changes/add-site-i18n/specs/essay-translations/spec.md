# Spec Delta

## Purpose

定义随笔与 p/acc 宣言正文的三语翻译模型：同一篇文章在中、英、日三语下共享同一身份标识与页面路径形状，归档与正文只呈现当前语言的内容，缺译时不混入其它语言文本。

## ADDED Requirements

### Requirement: 译文共享文章身份

同一篇文章的不同语言版本 MUST 共享同一篇文章标识（同一 slug），并以语言字段区分版本；一份译文 MUST 只属于一种语言。

#### Scenario: 三语版本路径同位

- **WHEN** 某篇文章在三种语言下均有译文且标识为同一 slug
- **THEN** 其页面分别位于 `/en/essays/<slug>`、`/zh-cn/essays/<slug>`、`/ja/essays/<slug>`

#### Scenario: 一篇一语言

- **WHEN** 同一语言下出现两份标识相同的文章
- **THEN** 构建失败并指出重复标识，而不是任选其一静默发布

### Requirement: 文章级属性在各语言间一致

发布日期、发布/草稿状态与 AIGC 标记 MUST 属于文章级属性，同一篇文章的三语版本 MUST NOT 出现日期或披露标记不一致。

#### Scenario: 译文共享发布日期

- **WHEN** 某篇文章的英文译文在归档中被列出
- **THEN** 该日期与中文、日文译文页面显示的日期相同

#### Scenario: 草稿状态对所有语言生效

- **WHEN** 某篇文章被标记为草稿
- **THEN** 它的任何语言版本都不出现在归档中，也不生成可访问页面

### Requirement: 归档只呈现当前语言

随笔归档 MUST 只列出当前语言存在译文的文章，标题 MUST 使用该语言译文的标题，排序 MUST 为发布日期倒序，且 MUST NOT 混入其它语言的文章条目。

#### Scenario: 只列出已翻译文章

- **WHEN** 站点有 3 篇文章，其中 2 篇有日文译文，用户访问 `/ja/essays`
- **THEN** 归档只列出这 2 篇的日文标题

#### Scenario: 当前语言无任何译文

- **WHEN** 用户访问某语言归档且该语言下没有任何已发布译文
- **THEN** 页面显示该语言的空状态文案，而不是空白列表或其它语言的文章

#### Scenario: 日期格式三语一致

- **WHEN** 归档在三种语言下渲染同一天
- **THEN** 三者都使用 `YYYY.MM.DD` 的数字日期格式，不带月份名称，使归档行的列宽保持一致

### Requirement: 缺译不混排语言

当某篇文章缺少当前语言译文时，站点 MUST NOT 用其它语言正文填充该语言的页面，也 MUST NOT 在该语言归档中列出该文章。

#### Scenario: 缺译文章无该语言页面

- **WHEN** 某篇文章只有中文译文，用户访问 `/ja/essays/<slug>`
- **THEN** 该地址没有内容页面，站点不展示中文正文冒充日文页面

#### Scenario: 从其它语言页面切换时回落

- **WHEN** 用户停留在某篇文章的中文页面并点击 日本語，而该文章没有日文译文
- **THEN** 用户进入 `/ja/` 首页，且不出现 404 错误提示

### Requirement: 宣言正文三语覆盖

`p/acc` 宣言页 MUST 在三种语言下各有完整正文与标题，用户 MUST 能从任意语言版本切换到其余两种语言的同一宣言页。

#### Scenario: 三语宣言均可访问

- **WHEN** 用户分别访问 `/en/what-is-p-acc`、`/zh-cn/what-is-p-acc`、`/ja/what-is-p-acc`
- **THEN** 三者都返回该宣言的完整正文，正文语言与路径语言一致

#### Scenario: 宣言页语言切换

- **WHEN** 用户从 `/zh-cn/what-is-p-acc` 点击 English
- **THEN** 用户进入 `/en/what-is-p-acc`，而不是英文首页

### Requirement: 翻译缺口在构建期可发现

构建或校验 MUST 能以可读方式报告"某篇文章缺少某语言译文"与"某语言译文缺少文章标识"两类缺口，使发布前三语覆盖情况可判断。

#### Scenario: 报告缺译清单

- **WHEN** 构建前执行翻译完整性检查且存在缺译
- **THEN** 输出列出文章标识与缺失的语言，且不因缺口而中断站点构建

#### Scenario: 全部译文齐备时检查通过

- **WHEN** 每篇已发布文章在三种语言下均有译文
- **THEN** 完整性检查无缺口输出并以成功状态结束
